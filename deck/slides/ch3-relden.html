CHAPTER 3 · RELATIVE DENSITY

How dense is this sand, really?

Dr = (emax − e) / (emax − emin)

Same thing with γd: Dr = [(γd − γd,min) / (γd,max − γd,min)] × [γd,max / γd]

FIELD EXAMPLE (3.7)

emax 0.75, emin 0.40, e = 0.67: Dr = 22.9%, loose

CORRELATION EXAMPLE (3.8)

emax 0.875, emin 0.525, e = 0.66: Dr = 61.4%, medium

emax = loosest state = lowest γd. emin = densest state = highest γd. Granular soils only.

Chapter 3 · Weight–volume

Relative density runs from 0 percent (loosest) to 100 percent (densest) and only makes sense for sands and gravels. The e version is the easiest to compute. If you are given unit weights instead, use the second formula, and remember gamma d min goes with e max.
