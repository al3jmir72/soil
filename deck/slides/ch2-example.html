1. READ THE CURVE

D60 = 0.41, D30 = 0.185, D10 = 0.09 mm

2. UNIFORMITY

Cu = 0.41 / 0.09 = 4.56

3. CURVATURE

Cc = 0.185² / (0.41 × 0.09) = 0.93

Cu < 6 and Cc < 1, so this sand is poorly graded.

Chapter 2 · Origin of soil

Percent finer for each row is (450 minus cumulative retained) divided by 450. For example, sieve number 40: cumulative retained 173.7, so finer is 276.3 over 450, which is 61.4 percent. D values come from the plotted curve, interpolating on the log axis. Exam habit: always check BOTH Cu and Cc before saying well graded.
