Ch. 2 · Grain size

% finer = (total − cumulative retained) / total × 100

Ch. 3 · Weight–volume

e = n / (1 − n) S·e = w·Gs

γd = Gs γw / (1 + e) = γ / (1 + w)

Dr = (emax − e) / (emax − emin)

Ch. 4 · Plasticity

PI = LL − PL LI = (w − PL) / (LL − PL)

A = PI / % clay A-line: PI = 0.73 (LL − 20)

SL = wi − Δw SR = M2 / (Vf ρw)

Ch. 5 · Classification

GI = (F200 − 35)[0.2 + 0.005 (LL − 40)] + 0.01 (F200 − 15)(PI − 10)
