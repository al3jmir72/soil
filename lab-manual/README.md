## About the conversion

- The text is complete (a word count against the PDF's text layer differs only in hyphenated compounds). Greek letters, subscripts and superscripts are kept (`W<sub>ae</sub>`, `cm<sup>3</sup>`).
- Equations are plain text, not LaTeX. A fraction is written inline as `numerator/denominator`, with brackets where needed, for example `V<sub>aj</sub> = W<sub>wj</sub>/γ<sub>w</sub>`. Long multi-line equations may read less cleanly than in the PDF; check the PDF when an equation looks ambiguous.
- Ruled tables became Markdown tables. The blank data sheets at the end of each experiment are kept as text.
- Figures and charts are cropped images placed after the text that precedes them, so a caption can sit a few lines away from its picture. The alt text gives the PDF page.
- Typos and symbol inconsistencies of the original (for example γ and ρ for density) are kept as written.
